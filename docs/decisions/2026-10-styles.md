# Styles and charters: decisions (Oct 2026)

Guiding rule: a theme is self-contained. Anything that holds for every theme on
every desktop (the meaning machinery) lives once in the pipeline. Anything about
how a world looks lives in that theme's file. No per-theme fields outside the
theme file, and no neutral fallbacks.

1. PR #4 (headroom). Apply only the `final_image_prompt()` refactor (one
   join used by build() and sweep.py). Do not add HEADROOM_SUFFIX. Framing
   problems are fixed inside the theme that causes them.
2. Charter required. Remove every unchartered fallback. A missing or invalid
   field is a loud error naming the theme and field. No neutral fallbacks,
   including the no-texture path. A full usage test runs before any deletion.
3. Label is display-only. Stage 2 no longer receives the label (after a
   prompts-only comparison confirms no loss).
   Done 2026-10-16: 7 styles x 3 cells x 3 registers on gpt-5.4, Stage 1.5
   shared between arms. Studio, artist and film names: 0 with the label, 0
   without; no loss of world in the paired prompts. Names still reach the
   image model through the symbolist, cosmic and ghibli suffixes (see 10).
4. One file per theme: `styles/<key>.toml` plus a REQUIRED `styles/<key>.jpg`
   preview. `[light]` (lo/mid/hi) is required in every theme; the global light
   lines are removed. The pipeline keeps: wallpaper rule, exposure bands,
   registers and families, actor kinds, wear scale, validator.
5. User themes live in `~/.config/astro-arc/styles/`. A user file with a
   shipped theme's key is ignored with a warning. User themes show as
   "(custom)". A theme that fails validation stays in the dropdown as
   "(Failed Validation)", cannot generate, and offers "Fix with AI" /
   "Copy fix prompt". The maintainer builds this; no outside contributions.
6. No written curation policy; core themes are decided case by case.
7. Meaning check: `astro-arc-style meaning <file>` replays 8 real days
   prompts-only and a blind judge model scores hard/soft, near-duplicates and
   "favourite scene". It is a step in the theme-creation loop.
8. Schema rules: the suffix names technique only (no objects, weather or
   places); a palette that implies a time of day needs its own `[light]`;
   forcing a mood or relationship is allowed as the creator's choice but
   warns.
9. Create your own style: the schema ships as one agent skill; the button
   briefs the user's Omarchy default agent; a "Copy prompt" path serves web
   LLMs with import + validation in the panel. No LLM API fallback in the
   plugin. Paid renders use the user's own model/quality/size settings and
   show cost first.
10. Studio names: run a blind A/B on the Ghibli theme without the studio
    name; ship a neutral version if it holds. Legal review before any paid tier.

Rejected: adding jampick's Bosch, Atomic, Barbarian Pulp and Grindhouse Funk
to the shipped set. Considered for later: a website for sharing curated themes.
